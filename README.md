# Smart Contract Notes / Description

### 1. Football Prediction Market ⚽

An intelligent football prediction contract where users predict the outcome of a match: **HOME, AWAY, or DRAW**. After the match, GenLayer retrieves the final result from an external source and uses validator consensus to verify the score before permanently resolving the market.

**Key feature:** Real-world web data + AI verification + consensus-based result resolution.

### 2. Intelligent Escrow 🔐

An AI-powered escrow system that evaluates whether submitted work satisfies a natural-language task and its requirements. GenLayer analyzes the submission, scores the result, and reaches validator consensus before deciding **RELEASE, PARTIAL, or REFUND**.

**Key feature:** AI-based evaluation of real-world work and requirements.

### 3. Natural-Language Permission Engine 🧠

A smart authorization system where permissions are written as human-readable rules instead of rigid code. GenLayer interprets the policy and evaluates individual requests, returning **ALLOW, DENY, or REVIEW** after independent validator verification.

**Key feature:** Converts natural-language policies into verifiable on-chain authorization decisions.
